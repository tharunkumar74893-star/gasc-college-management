GASC COLLEGE MANAGEMENT SYSTEM — FINAL BUILD NOTES

இந்த ZIP-ல் Public Website, Login/Registration, Admin, Faculty, HOD, Student dashboards, Attendance, Timetable, Leave Management ஆகியவை ஒரே project ஆக இணைக்கப்பட்டுள்ளன. Original project pages, images, config.js மற்றும் CSS பாதுகாக்கப்பட்டுள்ளன.

முக்கிய DB பொருத்தங்கள்:
- உங்கள் live attendance_records schema-வில் attendance_status NOT NULL என்பதால் frontend மற்றும் automatic-attendance SQL அதையே எழுதுகிறது. status column இருந்தால் compatibility-க்காக அதிலும் அதே value எழுதப்படும்.
- உங்கள் live attendance_sessions.subject NOT NULL என்பதால் automatic session-க்கு 'Daily Attendance' subject பயன்படுத்தப்படுகிறது.
- உங்கள் live timetable_entries.day_of_week INTEGER என்பதால் Monday=1, Tuesday=2, Wednesday=3, Thursday=4, Friday=5, Saturday=6 என சேமிக்கப்படுகிறது; UI-ல் மீண்டும் day name காட்டப்படும்.
- Attendance auto schedule: 09:30 AM IST session creation; 10:30 AM IST-ல் மீதமுள்ள மாணவர்களுக்கு Absent. Student self-check-in trigger-ல் தனியாக அனுமதிக்கப்பட்டுள்ளது: signed-in student தனது சொந்த session-ல் மட்டும் 09:30–10:30 IST இடையே Present பதிவு செய்ய முடியும். Duplicate rows unique(session_id, student_id) மூலம் தவிர்க்கப்படும்.
- Student self-check-in என்பது signed-in account அடிப்படையில். உண்மையான Face Recognition / biometric matching இந்த build-ல் இல்லை; camera capture-ஐ face recognition என்று தவறாகக் காட்டவில்லை.
- Leave Management code இந்த integration-க்காக மாற்றப்படவில்லை.
